# Graph Family

MVP collaborativo per costruire e navigare un grafo genealogico familiare.

## Obiettivo

Permettere a una famiglia di creare un grafo condiviso di persone e relazioni con ruoli distinti:

- **Owner**: controllo totale del grafo.
- **Admin**: gestione completa di persone, relazioni e membri.
- **Member**: può creare contenuti e modificare solo ciò che ha creato.
- **Guest via link**: sola lettura, con link opzionalmente protetto da password.

## Stack MVP

- Next.js
- React
- TypeScript
- Supabase Auth
- PostgreSQL
- Supabase Storage
- React Flow (`@xyflow/react`)

## Funzioni MVP

1. Registrazione / login
2. Creazione famiglia
3. Gestione persone
4. Gestione relazioni familiari
5. Grafo interattivo
6. Ruoli Owner / Admin / Member
7. Inviti collaboratori
8. Condivisione read-only via link
9. Password e scadenza link
10. Documenti opzionali associati a persone o relazioni
11. Activity log
